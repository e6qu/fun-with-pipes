The remaining runtime ownership boundaries need explicit lifetime policies, and several allocation paths perform unchecked size arithmetic. This bundle records the argument, result, callback, retention, teardown and cycle policy for all 177 fallback declarations, while keeping their existing tracing-compatible behavior.

It checks structural buffer growth and allocation failure, array and bump allocation limits, device output/workspace sizes, and empty kernel stack access. Kernel constants use the existing F64 bit decoder. Interpreter and native paths preserve malformed-kernel, argument and callback trap order. CI actions move to Node24, and current documentation replaces obsolete preparation instructions.

Validation includes Linux, ARM and Intel preflights; raw-interpreter comparisons; O1/O2 native binaries; GC stress/verification and reuse controls; ASan/UBSan and deliberate guard/cleanup omissions; codec artifacts; type snapshots; and exact-source ownership inventory checks. Full exact-head platform and documentation gates are required before squash merge. Phase 2 acceptance still requires the actual merged-source audit. No tracing-free or timing claim is made.
